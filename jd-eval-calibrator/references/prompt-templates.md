# 网页端双框prompt转化模板（prompt-templates）

将评估细则转化为网页端评估工具可直接粘贴的两个prompt文本块。适用前提：网页端仅有"岗位职责""岗位要求"两个文本入口，无系统prompt、无few-shot上传位。

## 1. 转化分工原则

| 输入框 | 内容来源 | 作用 |
|---|---|---|
| 岗位职责框 | 细则2.1节（原职责照抄）+ 新写"评估导引" | 帮模型理解岗位本质：核心交付物是什么、看重什么、不看重什么 |
| 岗位要求框 | 细则2.2-2.4、三、四、五、六章的浓缩 | 模型的执行程序：门槛→打分→判定→认定→禁令 |

禁止入框：细则第一章（背景机理）与第九章（落地建议）——给人看的，放进去只会稀释模型注意力。

评估导引句式："本岗位核心交付物是{一句话}。评估简历时重点考察：{2-3个核心信号}，而非{常见误判维度}（如院校名气/公司名气/行业出身）。"

## 2. 字数受限时的砍削顺序

岗位要求框超字数时按序砍削，骨架（硬性门槛、评分规则、判定规则）永远不动：

1. 先删【加分项】整段（影响最小）
2. 再压缩【认定规则】中次要的等效条款（保留专业认定与用工形式等效）
3. 再将多条【禁令】合并为一句："以上所有'优先'均为加分项不得否决；院校、行业出身、用工形式、是否应届均不得作为拒绝理由"
4. 仍超限：评分规则中各档位的"认定标准"长描述缩为关键词

## 3. 岗位职责框模板

```
{岗位名称}（{工作地点/性质}）

【岗位职责】
{原JD职责逐条照抄}

【评估导引】本岗位核心交付物是"{核心交付物一句话}"。评估简历时重点考察：{核心信号1}、{核心信号2}、{核心信号3}，而非{误判维度}。
```

## 4. 岗位要求框模板

> **默认用"去刻度精简版"（4.1）**：剥离数值刻度，仅保留定性档位认定+门槛+认定规则+禁令+判定样例。实测数字人岗此版与人工一致率58%，高于完整刻度版约50%（见SKILL.md认知#9）。完整刻度版（4.2，含分值与≥60通过线）作为备选，仅在模型未微调/微调很轻、或网页端强制要求输出分数时使用。

### 4.1 去刻度精简版模板（默认）

```
【硬性门槛】任一不满足直接判"不通过"：
{细则门槛逐条浓缩，纯二元}

【评估维度】（综合判断，不做分数累加）
从学历与专业、院校、相关经验、作品成果四个维度综合评估。相关经验是最高权重信号，作品成果次之，院校仅加分不否决。

【核心能力锚定】（先锚定能力内核，再判档位；按"能力是否同构"定档，而非按关键词是否命中）
本岗位核心能力内核：{一句话描述岗位真正要的能力，不是关键词，如"TTS监棚=棚内录制流程把控+发音/声学质量判断+音频交付标准把控"}。
- 过度乐观陷阱（看似相关、实则泛化，不得等同核心胜任力）：{列出字面相近但能力不同构的背景，如"纯音乐混音/游戏音效/影视配乐≠TTS录制监棚，按B/C档认定，不得因含'音频'字样直接给S档"}。
- 过度保守陷阱（看似不相关、实则高度可迁移，不得判零）：{列出能力同构但字面不同的背景，如"配音导演/ADR指导/录音助理/棚内录音工程，在棚内作业+音频质量把控+发音声学判断上与监棚同构，按A档及以上认定，不得判'零相关'"}。

【经验档位认定】（归入最匹配的一档，不写分值）
S档（最强信号）：{目标领域直接经验关键词}
A档（强信号）：{相邻经验关键词}
B档（相关信号）：{基础相关经验关键词}
C档（边缘但有效信号）：{边缘经验关键词}。注意：C档是有效相关经验，不是"无经验"。

【判定规则】
- 经验达S/A档：通过。
- 经验为B/C档，且专业或成果至少一项有相关支撑：通过。
- 完全无相关背景（门槛两项均无）：不通过。
- 某维度信息缺失时按已有信息综合判断，不得因信息缺失直接判不通过。

【认定规则】
{专业开放式认定/经验形式等效/专业-经验独立/门槛"或"逻辑，逐条一句}
末条固定加："专业认定与经验认定独立执行：有S档直接经验者不论专业名称均进入评估，不因专业不相关否决"

【禁令】
{细则第六章逐条，保持禁令句式}
必含两条通用禁令：①求职意向不得作为否决依据；②休学/复读/延毕/五年制本科属正常学制变动，不得视为异常

【加分信号】（仅增强通过倾向，不参与否决）：{原JD"优先"项归位}

【判定样例】（标定模式必附2-3条，优先选边缘通过样本）
{一句式：院校+专业+学历，关键经验，成果→通过（纠正的误判点）}
```

### 4.2 完整刻度版模板（备选，含数值分值）

```
【硬性门槛】任一不满足直接判"不通过"：
{细则2.2节逐条浓缩}

【评分规则】满足门槛后打分，满分100：
{细则第三章四维度，每维度一行：维度名（分值）：各档=分值}

【判定规则】总分≥60通过；<60不通过。某维度信息缺失时按该维度最低档给分，不得因信息缺失直接判不通过。

【认定规则】
{细则第四章专业认定/经验等效/工具同效，逐条一句}
末条固定加："专业认定与经验认定独立执行：即使专业名称不在认定表中，只要存在S档直接经验，即按豁免档进入评分流程，不得在门槛阶段因专业名称否决"

【禁令】
{细则第六章逐条，保持禁令句式}
必含两条通用禁令（所有岗位适用）：①"简历中的求职意向字段仅为候选人偏好参考，不得作为否决依据，按实际能力与经历正常评分"；②"休学/复读/延毕/五年制本科属正常学制变动，不得视为异常或作为否决/降分依据"

【加分项】仅用于同分排序，不参与否决：{细则2.4节}
{few-shot样例，仅标定模式}
```

## 5. 标定模式的few-shot样例写法

从细则第八章回测表中选2-3个**最能体现误判纠正**的样本，浓缩为一句式判定样例，附在禁令之后：

- 选样原则：优先选"边缘但通过"的样本（独立学院、应届、非典型背景、无直接经验者），其次选1个标杆样本。不选"明显该过"的样本（对模型无校准价值）。**特别优先选命中#10-#13模式的样本**：求职意向不匹配但能力达标者、仅有C档经验者、专业完全不相关但有S档经验者、休学/延毕者——这四类是最高频假阴性来源。
- 句式：`示例：{院校}{专业}{学历}，{关键经验}，{成果}→通过（{纠正的误判点}）`
- 样例中的分数可省略，除非网页端支持输出分数。

## 7. 完整实例B（音乐评测岗·标定模式，含few-shot）

岗位职责框：

```
多模态音频评测助理—音乐方向（杭州驻场）

【岗位职责】
负责复杂音频数据项目执行（频谱修复、说话人识别、情感识别、话语意图分析、副语言识别标注等）；对AI生成音乐进行偏好评估，合作构建AI音乐核心评分维度体系；根据听测反馈产出评测报告与优化建议；语音合成效果评测（音色相似度、音质水平、字音韵律等）；构建优化数据集（语料改写、prompt编写、内容收集）；完成Good/Bad Case拆解与归因分析；对个人数据准确率和有效产量负责。

【评估导引】本岗位本质是"用音乐专业能力给AI生成的音频/音乐打分"。评估简历时重点考察：音乐/音频专业功底、音频内容生产或评测标注经验、可验证的音乐或音频成果，而非院校名气、是否硕士、有无大厂正式编制。
```

岗位要求框：

```
【硬性门槛】任一不满足直接判"不通过"：
1. 非统招本科学历（专升本/自考/成教不通过；统招本科及以上、在读应届均通过）
2. 无任何音乐/音频相关背景（专业不含"音乐/音频/录音/声音/器乐"字样，且无音乐行业经验，且无音乐类成果证明）
3. 明确拒绝杭州现场办公

【评分规则】满足门槛后打分，满分100：
一、学历与专业（25分）：本科及以上=5分；专业核心档（录音艺术/音乐制作/电子音乐/音乐科技/作曲/音乐学/声乐/器乐/音乐表演/影视配乐/声音设计/音乐教育）=20分；相邻档（音乐史论/音乐人类学/艺术管理等理论方向，须附音乐技能证明）=15分；豁免档（本科非音乐但硕士音乐，或2年音乐行业全职，或10年器乐学习）=12分
二、院校（10分，只加分不否决）：专业音乐学院（央音/上音/国音/沈音/川音等）、伯克利/洗足学园等国际知名音乐学院、985/211=10分；其他专业艺术院校（南艺/浙传/西音等）及海外正规院校=8分；其他统招本科（含独立学院）=6分；院校识别不了=8分
三、相关经验（40分，取最高档不叠加）：S档=音频/音乐类数据标注、模型评测、AI训练师、生成内容审核（含大厂外包、驻场、实习）=40分；A档=AI音乐制作（Suno/ACE等）或AI音乐/音频产品公司任职=32分；B档=录音、混音、音效、配乐、母带等专业音频制作经验（含游戏音频、影视音频）=25分；C档=音乐教学（含钢琴/声乐/器乐/乐理教学、见习/代课）、演出、策划等其他音乐行业经验=15分。注意：C档是15分，不是"无经验"0分
四、作品成果（25分）：提供作品/项目链接或省级以上专业比赛获奖=20分；简历含详实项目描述（乐评、论文、音频工程案例、演出记录均可）或持有考级证书（八级及以上）=15分；仅文字自述无佐证=5分

【判定规则】总分≥60通过；<60不通过。某维度信息缺失时按该维度最低档给分，不得因信息缺失直接判不通过。

【认定规则】
1. 专业认定为开放式：含"音乐""音频""录音""声音""器乐"字样的专业默认相关；播音主持、影视制作等边缘专业按相邻档15分认定
2. 经验等效：音频标注、数据标注、AI训练师、内容审核、生成审核、Caption标注、模型评测、质检均认定为S档直接经验；外包、驻场、供应商派遣视同正式项目经验，不因用工形式降级；实习、兼职、校园项目、比赛、毕设与正式经验等效，不设时长下限
3. 工具佐证：简历出现Pro Tools/Logic Pro/Cubase/Reaper/Studio One/Sibelius/Suno/ACE Studio/鬼手/Wwise/FMOD/Waves/iZotope RX/Melodyne任一工具，作为专业与经验档位的佐证信号
4. 专业认定与经验认定独立执行：即使专业名称不在认定表中，只要存在S档直接经验，即按豁免档进入评分流程，不得因专业名称判不通过

【禁令】
1. JD中"重点本科/硕士优先"等所有"优先"表述均为加分项，对加分项执行否决属于逻辑错误，必须禁止；本科生、在读应届必须正常进入评分流程
2. 专业列表不得穷举化执行：录音艺术、电子音乐制作、音乐人类学、爵士钢琴、影视配乐、游戏声音设计、音乐表演（笙/古琴/民族器乐等）均为相关专业
3. AI/标注经验是最高档加分而非准入条件：无AI经验的制作型/教学型/演奏型候选人按B档或C档给分，不得判不通过，不得判"无相关经验"
4. 海外院校（伯克利各校区、洗足学园、庆熙大学、日本尚美学园等）与独立学院均为有效学历；识别不了的院校按8分给分
5. 本科非音乐+硕士音乐按豁免档给12分，不得判专业不符
6. 简历中的"求职意向"字段仅为候选人偏好参考，不得作为否决依据，按实际能力与经历正常评分
7. 音乐教学、演奏、演出经验属于C档（15分），不是"无经验"（0分）；见习、代课、短期教学也按C档给分

【加分项】仅用于同分排序，不参与否决：硕士学历；重点本科；精通乐理/和声/声学及录音技术；跨流派音乐鉴赏能力；熟练DAW或AI音乐工具

【判定样例】
示例1：匿名样本A：相关专业本科在读，驻场音频标注实习+节目混音，附作品集链接→通过（应届、本科均不影响，S档经验40分）
示例2：匿名样本B：独立学院相关专业本科，音频模型标注经验→通过（独立学院不否决，S档经验40分）
示例3：匿名样本C：相关专业本科应届，短期教学见习+专业技能证书→通过（教学见习=C档15分，考级=成果15分，总分≥60）
```

## 8. 粘贴后验证流程

1. 粘贴两框后，先取3-5份已有明确人工结论的简历试跑（必含1-2份历史上被AI误杀的样本）。
2. 判定不一致的case：分析其命中的误判点，补写禁令或调整档位描述后重跑。
3. 验证通过后再批量使用；每月用新人工判定结果复查，命中新误判模式时回写细则第六章与本prompt。
