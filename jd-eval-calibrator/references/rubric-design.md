# 权重设计方法论（rubric-design）

设计评估维度、权重、档位锚点与通过线的完整方法。标定模式全流程使用；改写模式使用第2、5节套默认值。

## 目录

1. 维度框架（默认四维度）
2. 权重分配的区分度启发式
3. 档位锚点写法
4. 通过线设置
5. 无样本默认模板（改写模式专用）
6. 质量检查清单

---

## 1. 维度框架（默认四维度）

默认使用四维度，总分100：

| 维度 | 内涵 | 典型子项 |
|---|---|---|
| 学历与专业背景 | 学历层次（达标性）+ 专业匹配度（区分性） | 核心专业/相邻专业/豁免情形 |
| 院校层次 | 只加分、不否决 | T0/T1/T3分层 |
| 相关经验匹配 | 取最高档、不叠加 | 直接经验/相关经验/基础经验/边缘经验 |
| 作品与成果证明 | 可验证的成果物 | 链接/获奖/详实项目描述 |

允许按岗位特性调整维度（如技术岗加"技能证书"维、管理岗加"团队规模"维），但保持"1个达标性维度 + 2-3个区分性维度 + 1个证据维度"的结构。

## 2. 权重分配的区分度启发式

权重不由"重要性直觉"决定，由样本区分度决定：

- **区分度最高的维度给最高权重**（通常30-40%）。判断方法：看哪个维度上通过样本与"理想候选人画像"的方差最大、且与人工判定最相关。业务岗通常是"相关经验"，技术岗可能是"技能匹配"。
- **全员达标的维度压缩权重**（5-10%）。样本中本科硕士都通过了，说明学历只是门槛——给达标性小分，腾出权重给区分性维度。
- **事实硬门槛显性化**（20-25%）。全员都有作品证明→设为独立维度+在硬性门槛中声明，防止模型忽略。
- **易误判维度给"安全带宽"**。院校维度最高档与最低档分差控制在5分以内，从机制上杜绝"以校取人"。

## 3. 档位锚点写法

每个维度2-4档，每档四要素齐全：

| 要素 | 要求 | 反例 |
|---|---|---|
| 档位名 | 可客观归类，不含"优秀/良好"等主观词 | "经验丰富档"（无法执行） |
| 认定标准 | 用可观察事实描述：公司类型、动作、产出物、时长（如需） | "熟悉AI评测"（"熟悉"无法验证） |
| 得分 | 相邻档分差5-8分；最高档与次高档拉开差距体现信号强度 | 每档差1分（无区分度） |
| 对应正样本 | 标定模式必填，映射匿名样本ID；改写模式填"待标定" | 凭空虚设无样本对应的档位 |

经验维度命名推荐信号分级：S档（目标领域直接经验）/ A档（相邻经验）/ B档（基础相关经验）/ C档（边缘经验）。

## 4. 通过线设置

- **标定模式**：通过线 = 边缘样本得分 − 安全余量（≥5分）。做法：先给全部正样本打分，找到最低分（即"人工认可的底线候选人"），通过线设在其下5-10分。
- **改写模式**：默认通过线60，上线后按首批人工判定结果校准。
- 判定为纯二元结果：总分≥60通过，<60不通过。不设"复核区间""转人工"等中间态。
- 通过线必须是整数，且文档中写明"总分≥X通过，<X不通过"。

## 5. 无样本默认模板（改写模式）

无样本时套用以下默认结构，并在文档中显著标注"默认值，待回测校准"：

- 学历与专业 25%（学历达标5% + 专业匹配20%：核心档20/相邻档15/豁免档12）
- 院校 10%（T0=10 / T1=8 / T3=6，分差≤4）
- 经验 40%（S=40 / A=32 / B=25 / C=15）
- 作品成果 25%（可验证链接或省级以上获奖20 / 详实项目描述15 / 仅自述无佐证=5）
- 通过线60（总分≥60通过，<60不通过，无中间态）

硬性门槛通用四条（按岗位替换括号内容）：①统招本科及以上（含在读应届，非统招不通过）；②专业背景满足认定总表或豁免条件；③能提供可验证成果证明；④接受（工作地点/用工形式）。

## 6. 质量检查清单

交付前逐项核对：

- [ ] 每个档位都能映射到真实样本（标定模式）或标注"待标定"（改写模式）
- [ ] 全部正样本回测≥通过线，且最低分高出通过线≥5分
- [ ] 院校维度任何档位不得成为拒绝理由
- [ ] 不存在"优先"被写在门槛或维度认定标准里
- [ ] 专业/经验枚举均声明开放式
- [ ] 实习/外包/兼职/项目经验的等效认定已写明
- [ ] 跨界学历、海外院校、在读应届各有显式归类规则
- [ ] 信息缺失时的处理规则（按最低档给分+标注，不得直接拒绝）
- [ ] C档经验显式标注分值（如"C档=15分，不是0分"），并写明"教学/见习/代课/短期经验也按C档给分，不得判无经验"
- [ ] 门槛规则中声明"专业认定与经验认定独立执行"：有S档直接经验的候选人不论专业名称均按豁免档进入评分
- [ ] 禁令中包含"求职意向不得作为否决依据"（通用规则，所有岗位适用）
- [ ] 禁令中包含"休学/复读/延毕/五年制本科属正常学制变动，不得视为异常"（通用规则）
