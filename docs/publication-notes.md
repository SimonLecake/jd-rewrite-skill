## 内容来源

本仓库展示基于作者提供的以下材料整理：

- `jd-eval-calibrator (2).skill`，包内版本为 **4.1.0**：双模式工作流、17 类误判模式、权重设计与双框 Prompt 模板。
- JD Evaluation Calibrator GitHub README 草案：项目定位和交付结构。
- AI Application Portfolio 的 Project 1：作者角色、55% → 70% 业务一致率记录和标定样本说明。
- Error Case RAG 人机反馈闭环设计 V3：反馈流程、案例字段、职责分工与目标。
- V4 架构验证补充：上下文注入能力缺失，以及 RAG / Fine-tuning 的实施前提比较。

原始 Word 文档、完整申请作品集、真实简历和企业评估日志没有作为本次更新的公开附件上传。

## 文件与版本

- 保留原有 `.skill` 文件名，便于已有链接继续使用。
- `jd-eval-calibrator/` 是可直接浏览的文本源码，内容与当前包逐文件一致。
- 公开版将参考文件中的实名样本和部分可识别案例组合替换为匿名编号或概括描述；没有新增模型能力。
- 主工作流版本保留 **4.1.0**。本次更新是展示、公开源码和样本去标识处理，不宣称新的功能版本。
- 示例目录中的 JD 改写与案例 JSON 为人工编写的说明性材料，不是运行日志或实测效果。

## 保留的历史内容与当前使用建议

Skill 的 Prompt 参考文件同时保留去刻度默认模板和较早的完整刻度实例；使用时以主 Skill 的“去刻度精简版”默认说明为准，不能把历史实例误读为所有模型都应采用的模板。

Skill 的样本回测要求与独立质量验证是两件事：把已知案例修正到一致，并不能证明新样本同样一致。公开 README 和评估说明明确标注了这个边界。

本次匿名化更新只作用于当前文件与下载包，未重写 Git 历史；旧提交不属于当前已去标识的公开版本。
